Windows 声音问题诊断与修复说明
================================
日期：2026-10-15
症状：有时候不播放声音，或者突然没声音

一、排查结论（按可能性排序）
----------------------------
1. 快速启动是开着的（HiberbootEnabled = 1）
   关机再开机时驱动不会真正重新初始化，"关机后就没声音"最常见的原因。

2. Nahimic 音效服务在跑（A-Volute Nahimic 3 APO 3.5.3.0，2022 年的）
   戴尔预装的音效层，会把自己的 APO 注入 Realtek 输出链路，
   是"用着用着突然没声"的头号嫌疑。

3. 输出设备的独占模式是开着的（默认）
   某个程序（游戏、ASIO、变声软件）一旦独占设备，其它程序全部静音，
   直到那个程序退出。

4. 音频设备允许 Windows 断电省电
   空闲一段时间后编解码器被断电，有时唤不回来。

5. 输出设备会被抢走：机器上有
   · Voicemeeter 虚拟声卡（VB-Audio，RVC 变声用）一堆虚拟端点
   · NVIDIA / Intel 显示器音频（HDMI，接显示器时会被抢）
   · 两个蓝牙设备（OnePlus Ace 6t、花未P40）
   Windows 在新设备连接时可能把默认输出切过去，那个设备又不出声 → 听起来就是"突然没声音"。
   当前默认输出是正常的：扬声器/听筒 (Realtek(R) Audio)，没有跑偏。

6. Realtek 声卡驱动是 6.0.9394.1（2022-08-09），比较老。
   建议之后去戴尔官网更新一次 Realtek 音频驱动。

7. 事件日志里最近 7 天没有音频服务崩溃记录 —— 说明不是"服务已经死了"，
   更符合上面 1-5 这种"慢性"故障。

二、需要你点一下（必须管理员权限，我这边点不了 UAC）
--------------------------------------------------
桌面上有个图标：**修复声音(双击我)**
双击它 → 弹出"用户帐户控制" → 点【是】→ 10 秒左右弹窗提示"声音修复完成"。

三、这一步会做什么（全部可还原）
--------------------------------
0. 先把这个文件里"原始值"记到 D:\ai\audio\audio-backup.json
   （快速启动原值、Nahimic 的启动类型与当时是否在跑、每个要改的端点改前的独占模式值）
1. 关闭快速启动
2. 让 Windows Audio / Windows Audio Endpoint Builder 服务崩溃后自动重启
   （sc failure，5 秒后重启，最多 3 次）
3. 关闭音频控制器的"允许计算机关闭此设备以节约电源"
4. 关闭默认输出设备的独占模式（允许独占 + 独占优先 都置 0）
5. 停用 Nahimic 服务（改为手动启动，不再自动跑）
6. 安装并启动守护任务 **DSH-AudioGuard**（开机自启）
   · 每 45 秒检查一次：声音服务是否在跑、默认输出设备是否还活着
   · 发现异常自动重启音频服务（1 小时最多 3 次，防抖）
   · 状态写到 D:\ai\audio\guard-state.json，日志 D:\ai\audio\guard.log

四、还原
--------
桌面：**还原声音设置**（同样点一次"是"）
按 audio-backup.json 把上面 0-5 恢复、删掉守护任务、重启音频服务。
注意：如果 audio-backup.json 不在了，"还原"**不会猜**——Nahimic 的启动类型和快速启动
会保持原样不动（以前它无条件写成 Automatic / 1，会把本来是 Disabled 的服务变成开机自启），
只提示"原始值未知"。所以别删 audio-backup.json。

五、文件清单（都在 D:\ai\audio）
--------------------------------
修复声音.cmd / 修复声音(双击我).lnk      一键修复入口
Fix-Audio-AllInOne.ps1                  提权 + 执行修复 + 安装守护
Repair-WindowsAudio.ps1                 具体修复项（动手前先写 audio-backup.json）
lib\AudioBackup.ps1                     备份读写 + 日志编码修复（被上面两个脚本共用）
Revert-Audio.ps1 / 还原声音设置.lnk      还原（读 audio-backup.json）
AudioGuard.ps1                          声音守护
List-AudioEndpoints.ps1                 查看所有输出设备与默认设备
Get-AudioDefault.ps1 默认设备读取（WinRT + MMDevices 注册表，只读，备用）
audio-backup.json                       修复前的原始值（还原要用，别删）
repair-log.txt                          修复日志（只用 UTF-8 追加写，不会再出现 NUL 字节）
guard.log / guard-state.json            守护日志与状态

六、另外两个建议
----------------
· 手机蓝牙如果一直连着这台电脑，建议不必要时断开（蓝牙音频设备会抢默认输出）
· 之后更新一次 Realtek 音频驱动（现驱动 2022 年，戴尔官网或 Realtek 官网）
